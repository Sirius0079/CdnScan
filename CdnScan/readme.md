# CdnScan

# IP → ASN → Origin Analysis Tool

一个用于 **分析 IP 是否可能为真实源站** 的辅助工具，
通过 **ASN 归属 + 组织类型 + 出现特征**，对目标 IP 进行优先级判断。

------

## 1️⃣ 工具做了什么

本工具完成三件事：

1. **将 IP 映射到 ASN**
2. **根据 ASN 组织判断其网络类型**
3. **评估该 IP 成为真实源站的可能性**

最终输出：

- 终端可读分析结果
- Excel 表格，按“源站可能性”排序

------

## 使用方法（Usage）

将目标 IP 写入文本文件（如 `ip.txt`），一行一个，例如：

```
104.18.10.101
34.128.139.122
202.137.30.22
8.215.73.118
```

执行扫描

```bash
python cdnscan.py -f ip.txt
```

## 2️⃣ 核心原理说明

### （1）IP → ASN

使用 **Team Cymru Whois 服务** 批量查询每个 IP：

- ASN 编号
- ASN 所属组织（Org）

ASN 本质上代表 **IP 所属网络的真实拥有者**，
这是判断 CDN / 云厂商 / 企业自建网络的关键。

------

### （2）ASN → 网络类型

根据 ASN 组织名称进行分类：

| ASN Type             | 含义                             |
| -------------------- | -------------------------------- |
| CDN                  | 内容分发网络（几乎不可能是源站） |
| Cloud                | 公有云（可能性较低）             |
| Local IDC            | 本地数据中心 / 托管              |
| Local ISP            | 运营商网络                       |
| Enterprise / Unknown | 企业自建或未知                   |

> 一般来说：
> **越靠近企业自建网络，越可能是真实源站**

------

### （3）源站可能性评分（Origin Score）

综合以下因素进行评分：

- ASN 类型（是否为 CDN / 云）
- IP 是否被多个子域名重复指向
- 是否属于本地 IDC / 企业网段

最终给出结论：

| Conclusion       | 含义         |
| ---------------- | ------------ |
| 🔥 极可能真实源站 | 优先重点关注 |
| ⚠️ 可能真实源站   | 可进一步验证 |
| ❌ 低概率         | 可暂时忽略   |

------

## 3️⃣ 输出结果说明

### 终端输出

用于 **实时观察单个 IP 的分析过程**，便于快速判断。

### Excel 输出字段

| 字段         | 说明           |
| ------------ | -------------- |
| IP           | 目标 IP        |
| ASN          | ASN 编号       |
| Org          | ASN 组织       |
| ASN Type     | 网络类型       |
| Origin Score | 源站可能性评分 |
| Conclusion   | 自动结论       |

Excel 中会 **优先排列高价值 IP**，方便人工跟进。

## 4️⃣  典型红队使用场景

- CDN 后真实源站定位
- 子域名 IP 聚合分析
- 攻击面收敛
- WAF / CDN 绕过前置筛选
- 云资产与本地资产区分

------

## 5️⃣ 注意事项

- 本工具 **不是自动判断“一定是真实源站”**
- 它的目标是 **提高判断效率，减少无效测试**
- 高分 IP 建议结合：
  - HTTP / HTTPS Banner
  - TLS 证书 SAN
  - PTR（反向解析）
